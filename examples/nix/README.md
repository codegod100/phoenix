# Phoenix Nix Flake Example

A declarative Nix flake demonstrating reproducible development environments and package builds.

## Overview

This example was generated using the **Phoenix Pipeline** from the spec in `spec/nix-flake.md`. It demonstrates:

- Multi-system support (`x86_64-linux`, `aarch64-darwin`)
- Development shells with Node.js 20+ and git
- Package outputs with build-time metadata
- Formatter integration (`nixpkgs-fmt`)
- Automated checks
- Nixpkgs overlay

## Quick Start

```bash
# Enter the development shell
nix develop

# Build the package
nix build

# Run the result
./result/bin/phoenix-nix-example

# Run checks
nix flake check

# Format nix files
nix fmt
```

## Development

To modify this flake:

1. **Edit the spec**: `spec/nix-flake.md`
2. **Re-run pipeline**: `node .pi/skills/phoenix-pipeline/pipeline.js examples/nix`
3. **Update `flake.nix`** to match new requirements
4. **Test**: `nix flake check`

## Requirements

- Nix 2.4+ with flakes enabled
