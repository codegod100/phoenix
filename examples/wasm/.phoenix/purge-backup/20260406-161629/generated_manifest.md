## Implementation Details

### SQLite WASM API Pattern

Uses @sqlite.org/sqlite-wasm Worker1 Promiser with callback-based result capture:

```typescript
// For SELECT queries - use callback
const rows: T[] = [];
await promiser('exec', {
  dbId: dbId,
  sql: 'SELECT id, title FROM notes',
  callback: (row) => { rows.push(row.row); }
});

// For INSERT/UPDATE/DELETE - no callback needed
await promiser('exec', {
  dbId: dbId,
  sql: 'INSERT INTO notes (title) VALUES (?)',
  bind: ['New Note']
});
```

### Important Implementation Notes

- **Callback API**: Worker1 Promiser requires callbacks to capture query results
- **No RETURNING clause**: Select after insert/update to get full row data
- **COOP/COEP required**: OPFS only works with cross-origin isolation headers
- **TypeScript types**: All files include `_phoenix` traceability exports
- **Performance targets**: Search <100ms, Load <2s, 1000 notes capacity
- **Retry logic**: 3 attempts for failed saves with exponential backoff
- **Auto-save**: 500ms debounce on typing stop
