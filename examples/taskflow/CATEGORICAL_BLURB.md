The Phoenix pipeline treats every specification as a **theory**—a formal language of operations and equations that describe what the system should do. These theories are expressed as Generalized Algebraic Theories (GATs), which means each spec defines not just data structures, but the valid ways those structures can transform and relate to each other. When the pipeline reaches the codegen phase, it doesn't just concatenate files; it computes a **colimit**—a categorical "pushout" that merges all the individual theory fragments (IUs) into a single coherent whole. The colimit operation guarantees that shared concepts (like "Task" appearing in both Archive and Priority domains) are unified rather than duplicated, producing a deliverable where every piece fits together by construction, not by convention.
