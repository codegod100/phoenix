# Where Code Generation Actually Happens

## Overview

Actual code generation (string → string transformation) happens in **two main places**:

1. **Bundle generators** (`bundles/*/generate.rs`) - Primary location (NEW)
2. **Template bundle dispatch** (`src/pipeline/template_bundle.rs`) - Dispatcher (OLD infrastructure)

```rust
/// THIS IS WHERE STRINGS GET CONCATENATED INTO CODE
fn generate_express_code(config: &BundleConfig, routes_lit: &Literal) -> String {
    // Generate route handlers from Literal
    let routes_code = match routes_lit {
        Literal::List(route_list) => {
            route_list.iter().map(|route_lit| {
                generate_route_handler_js(route_lit, name)  // ← CODEGEN
            }).collect::<Vec<_>>().join("\n\n")
        }
        _ => generate_default_routes_js(name),
    };
    
    // THIS format!() CALL IS THE ACTUAL CODE GENERATION
    format!(r#"// phoenix: iu_id = "{}-api"
// Express API generated by Phoenix VCS
// Generated via: μ_config→code (Expr evaluation)

const express = require('express');
const cors = require('cors');

const app = express();
const PORT = process.env.PORT || {port};

// Middleware
app.use(cors());
app.use(express.json());

{routes_code}  // ← ROUTES INSERTED HERE

// Start server
app.listen(PORT, () => {{
  console.log(`🚀 {name} API server running on port ${{PORT}}`);
}});
"#,
        name.to_lowercase().replace(" ", "-").replace("_", "-"),
        port = port,
        routes_code = routes_code,  // ← EVALUATED ROUTES
        name = name
    )
}
```

## Summary: Where Code Gets Built

| Location | Function | What It Does |
|----------|----------|--------------|
| `bundles/*/generate.rs` | `generate_*_code()` | **Primary codegen** - pattern match on `Literal`, use `format!()` |
| `bundles/*/generate.rs` | `generate_route_handler*()` | **Route codegen** - individual handlers |
| `src/pipeline/template_bundle/*.rs` | `*_bundle()` | **Legacy** - template-based `format!()` |
| `src/pipeline/expr_bundle.rs` | `*_generator()` | **Infrastructure** - dispatches to bundles |

## The Key Insight

**Code generation is just `format!()` calls** - but WHERE you call it matters:

```rust
// ❌ TEMPLATE (old way): Strings with interpolation
format!("function {}() {{...}}", name)

// ✅ EXPR (new way): Data → eval → pattern match → format!
let lit = eval(&expr, &env, &config)?;  // Evaluate structure
if let Literal::Record(fields) = lit {  // Pattern match
    format!("function {}() {{...}}", extract(fields))  // Generate
}
```

The Expr layer gives us **structure preservation** - we can:
1. Verify the shape is correct at each layer
2. Transform algebraically before generating
3. Parse generated code back to Literal (bidirectional)

But the actual string building still happens via `format!()` - that's the final morphism.
