# Elena Dashboard

A modern fullstack application built with **ElenaJS** web components and **Hono** backend.

## Architecture

```
┌─────────────────────────────────────────┐
│           Client (Port 5173)            │
│  ┌─────────────┐ ┌─────────────┐       │
│  │WelcomeCard  │ │  TodoList   │       │
│  │  (Web Comp) │ │ (Web Comp)  │       │
│  └─────────────┘ └─────────────┘       │
│           ElenaJS Web Components        │
└─────────────────────────────────────────┘
                   │
                   │ Proxy /api
                   ▼
┌─────────────────────────────────────────┐
│           Server (Port 3000)            │
│                                         │
│   Hono HTTP Framework + Bun Runtime     │
│                                         │
│   Routes:                               │
│   • GET  /api/health                    │
│   • GET  /api/users                     │
│   • GET  /api/todos                     │
│   • POST /api/todos                     │
│                                         │
└─────────────────────────────────────────┘
```

## Features

### Frontend
- **WelcomeCard**: Hero section with gradient styling
- **TodoList**: Interactive todo management with API persistence
- **UserCard**: User profile with avatar initials
- **Shadow DOM**: Encapsulated styles per component
- **Reactive**: Automatic re-rendering on state changes

### Backend
- **Hono**: Fast, lightweight web framework
- **Bun**: Modern JavaScript runtime
- **CORS**: Cross-origin support for dev proxy
- **Logger**: Request/response logging

## Development

### Prerequisites
- [Bun](https://bun.sh/) runtime
- Nix (optional, for reproducible environment)

### Setup

```bash
# Install dependencies
bun install

# Or use Nix
nix develop
```

### Running

```bash
# Start both client and server
bun run dev

# Or separately:
bun run dev:server  # API on port 3000
bun run dev:client  # Vite on port 5173
```

### Building

```bash
# Type check and build
bun run build

# Preview production build
bun run preview
```

## Notes

**ElenaJS** is referenced from https://elenajs.com/ but this implementation uses standard Web Components (Custom Elements + Shadow DOM) as a demonstration. The API design follows modern component patterns:

- `connectedCallback()` - Mount
- `attributeChangedCallback()` - Props change
- `render()` - Update DOM
- Shadow DOM for style encapsulation
