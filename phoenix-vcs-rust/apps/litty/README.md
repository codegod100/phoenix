# Litty - Lit Todo App

A simple todo list application built with Lit Web Components and TypeScript.

## Features

- **Simple Counter**: Increment/decrement demonstration
- **Todo List**: Add, toggle, and delete todo items
- **Lit Web Components**: Uses reactive properties and shadow DOM

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `src/main.ts` - Main app entry with Lit components
- `index.html` - HTML entry point
- `package.json` - NPM dependencies (lit, typescript, vite)
- `tsconfig.json` - TypeScript configuration
- `vite.config.ts` - Vite build configuration

## Technologies

- [Lit](https://lit.dev/) - Web Components library
- [TypeScript](https://www.typescriptlang.org/) - Typed JavaScript
- [Vite](https://vitejs.dev/) - Build tool and dev server
