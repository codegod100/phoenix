# Litty - Lit Web Components App

## Overview
A fun Lit web components application with a cute kitty/neko theme.

## Features

### Components
1. **Hero Section** - Large hero with gradient background
2. **Counter** - Reactive counter with +/- buttons  
3. **Todo List** - Add, toggle, and delete todos

## Design Requirements

### Visual Theme
- **Background**: Cute kitty/neko (cat) themed background with soft pastel colors
- **Color Palette**: 
  - Primary: Soft pink (#FFB6C1) or lavender (#E6E6FA)
  - Secondary: Light peach (#FFDAB9) or mint (#98FB98)
  - Accents: White, cream, soft grays
- **Decorative Elements**: Cat paw prints, whiskers, ears silhouettes, hearts, stars
- **Style**: Kawaii/cute aesthetic with rounded corners and soft shadows

### Hero Component
- Gradient background with cat-themed colors (pink/purple/lavender)
- Title: "Welcome to Litty! 🐱"
- Subtitle: "A purr-fect web components demo"
- Decorative cat ears or paw prints in corners

### Counter Component
- Rounded card design with soft shadow
- Cat paw button icons instead of +/- text
- Background: Light mint or cream

### Todo List
- Soft rounded corners
- Checkbox styled as cat paw when checked
- Pastel colored list items

## Technical
- Framework: Lit 3.0
- Build: Vite
- Language: TypeScript
