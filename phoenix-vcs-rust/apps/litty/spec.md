# Litty - Simple Lit Web Components App

A simple web application using Lit framework for modern Web Components.

## Overview

**App Name**: litty  
**Framework**: Lit (Web Components)  
**Language**: TypeScript  
**Purpose**: A simple todo list app demonstrating Lit reactive properties and event handling

## Features

1. **Todo List Component**: Add, toggle, and delete todo items
2. **Counter Component**: Demonstrates reactive state with buttons
3. **Styled with CSS**: Uses Lit's CSS tagged templates
