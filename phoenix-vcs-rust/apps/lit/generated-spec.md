# Lit Demo App

A simple Lit web components application.

## Overview

- **Frontend**: Lit web components with reactive templates
- **Styling**: CSS-in-component with theme support

## Theme Configuration

- Theme: `arc-dark`
- Options: `catppuccin-mocha`, `arc-dark`

## Components

### LitApp
Root application container.
- Props: `title`
- Config:
  - `title` = `Lit Demo App`

### LitCounter
Reactive counter component.
- Props: `count`
- Features: Increment/decrement buttons

## Development

```bash
bun install
bun run dev
```
